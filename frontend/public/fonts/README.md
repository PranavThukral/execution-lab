# Locally hosted fonts

The current interface uses Inter for controls, body text and numbers, and Krub for headings.

- `inter-latin.woff2`: Latin subset, weights 400–700. License: `inter-OFL.txt`.
- `krub-600-latin.woff2` and `krub-700-latin.woff2`: Latin subsets, weights 600 and 700. License: `krub-OFL.txt`.

These three files total 71,924 bytes. Fonts load from this application; no font CDN request is made at runtime. Source files were downloaded from the official Google Fonts distribution. Both families use SIL Open Font License 1.1; their licenses are included here. Inter is preloaded and all faces use `font-display: swap`.

Upstream: [Inter](https://github.com/google/fonts/tree/main/ofl/inter), [Krub](https://github.com/google/fonts/tree/main/ofl/krub).
